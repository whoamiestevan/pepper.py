# 🐕 Pepper.py

**Pepper.py** is a Python combination generator with a dog companion.

It allows the user to enter 7 words, numbers, or symbols and generate
combinations from those inputs. The generated combinations can be saved
to a text file.

## 📌 Features

- ASCII dog companion
-  Enter 7 words, numbers, or symbols
-  Generate combinations
-  Show statistics
-  Estimate output file size
-  Save combinations to a text file
-  Show generation progress
-  Show generation time
-  Stop generation with `Ctrl+C`

## 🛠️ Requirements

- Python 3.x
- Linux, macOS, or Windows
- No external Python packages required
