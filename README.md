# 🐕 Pepper.py

A Python combination generator built through vibe coding and AI-assisted development.

## Features

- Generate combinations from 7 inputs
- Display generation statistics
- Estimate output file size
- Save combinations to a text file
- Show generation progress and time
- Stop generation with `Ctrl+C`

## Requirements

- Python 3.x
- No external packages required

git clone https://github.com/whoamiestevan/pepper.py.git
